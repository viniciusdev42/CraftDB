# Módulo 1

## Descrição

### O Módulo 1 refere-se a implementação de páginas e registros de tamanho fixo,a fim de armazenar os dados de forma persistente,consistente e ágil.A decisão mais difícil para a equipe foi implementar o **Isolamento entre Páginas**.Isso ocorreu devido à complexidade do código concorrente,o qual trata de múltiplas tentativas de acesso simultâneo,o qual não é um fenômeno determinístico.
